## 🔧 Installation

### Prerequisites

- PHP 7.4 or later
- Apache Web Server
- XAMPP, WAMP, or LAMP

### Setup

1. Clone the repository:

```bash
git clone https://github.com/Mourad-Tiferras/PHP-Project-UIC.git
```

2. Move the project folder to your web server directory:

**XAMPP**

```text
htdocs/
```

**WAMP**

```text
www/
```

3. Start Apache.

4. Open your browser and navigate to:

```text
http://localhost/mcq-quiz-app/client.php
```
